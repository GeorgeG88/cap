Supported format

UFW kernel log lines, with classic syslog or ISO 8601 timestamps:

Oct 19 14:02:11 host kernel: [UFW BLOCK] IN=enp0s8 OUT= ... SRC=... DST=... PROTO=TCP SPT=... DPT=... SYN URGP=0
2026-10-19T14:02:11.123456+03:00 host kernel: [UFW ALLOW] IN=enp0s8 ...

Lines that are not firewall entries are counted and skipped. Malformed firewall lines are counted and reported on the run page; they never stop the analysis.

Getting the log

On the Ubuntu firewall host: sudo cp /var/log/ufw.log ~/ufw.log && sudo chown $USER ~/ufw.log, then copy it to this machine (for example with a VirtualBox shared folder or scp).
